# Installation

## Requirements

| Requirement | Version |
|---|---|
| Dart SDK | `>=3.4.1 <4.0.0` |
| Flutter | Any release that bundles Dart 3.4.1 or newer (Flutter 3.22.1+) |

The package depends on `collection`, `meta`, and `shared_preferences`. You don't
need to add these yourself.

## Add the dependency

```bash
flutter pub add flutter_policy_engine
```

Or add it to `pubspec.yaml` manually and run `flutter pub get`:

```yaml
dependencies:
  flutter_policy_engine: ^2.0.0
```

## Import

The package has a single public entry point:

```dart
import 'package:flutter_policy_engine/flutter_policy_engine.dart';
```

Don't import files under `package:flutter_policy_engine/src/`. They are internal
and can change without notice.

## Optional: bundle a policy file

To load policies from a JSON file shipped with the app, declare it as an asset:

```yaml
flutter:
  assets:
    - assets/policies/
```

See [Policies & Roles](/core-concepts/policy-management) for the file format and
the [JSON Assets Demo](/examples/json-assets-demo) for a working example.

## Platform support

The engine itself is pure Dart plus Flutter widgets, so it runs on every platform
Flutter supports. `SharedPreferencesPolicyRepository` relies on the
[`shared_preferences`](https://pub.dev/packages/shared_preferences) plugin and
works wherever that plugin does (Android, iOS, web, macOS, Windows, Linux).

## Upgrading from v1

v2 is a complete rewrite with a new API and a new JSON schema. `PolicyManager`,
`PolicyProvider`, `PolicyWidget`, and the `allowedContent` key were removed.
Follow the [migration guide](/migration-v1-to-v2).
