# Role Management Demo

The second screen of the [example app](https://github.com/aspicas/flutter_policy_engine/tree/main/example).
It shows runtime role CRUD with `addRole`, `updateRole`, `removeRole`, and
`listRoles`, and keeps a role list in sync by listening to the controller.

## Listening for changes

`PolicyEngineController` is a `ChangeNotifier`. Every successful mutation calls
`notifyListeners()`, so the screen subscribes once and refreshes its list:

```dart
@override
void initState() {
  super.initState();
  _controller = PolicyEngineController.inMemory();
  _controller.addListener(_refreshRoles);
  _load();
}

@override
void dispose() {
  _controller
    ..removeListener(_refreshRoles)
    ..dispose();
  super.dispose();
}

Future<void> _load() async {
  await _controller.loadPolicies(kDemoPolicy);
  await _refreshRoles();
}

Future<void> _refreshRoles() async {
  final result = await _controller.listRoles();
  if (!mounted) return;
  setState(() {
    _roles = switch (result) {
      Ok(:final value) => value,
      Err() => const [],
    };
  });
}
```

Widgets under a `PolicyEngineScope` don't need a manual listener. `PolicyGate` and
`PolicyBuilder` re-evaluate on their own.

## Add

```dart
final result = await _controller.addRole(
  RoleEntity(
    name: RoleName('temp_role'),
    allowedResources: const {'dashboard', 'reports'},
  ),
);
```

If a role with the same name already exists, `addRole` replaces it.

## Update

```dart
final result = await _controller.updateRole(
  'temp_role',
  RoleEntity(
    name: RoleName('temp_role'),
    allowedResources: const {'dashboard', 'reports', 'analytics'},
  ),
);
```

`updateRole` removes the role named by the first argument and adds the new
entity. Give the new entity a different name to rename the role.

## Remove

```dart
final result = await _controller.removeRole('temp_role');
```

Removing a role that doesn't exist succeeds as a no-op.

## Reporting the outcome

Each call returns `Result<void, DomainFailure>`:

```dart
final message = switch (result) {
  Ok() => 'Done',
  Err(:final error) => 'Failed: ${error.message}',
};
```
