# JSON Assets Demo

The third screen of the [example app](https://github.com/aspicas/flutter_policy_engine/tree/main/example).
It loads its policy from a bundled JSON file through `FlutterAssetLoader`, so you
can change permissions without changing code.

## 1. Add the policy file

`example/assets/policies/user_roles.json`:

```json
{
  "roles": {
    "admin": {
      "allowedResources": ["dashboard", "settings", "users", "reports", "analytics", "admin_panel"]
    },
    "manager": {
      "allowedResources": ["dashboard", "reports", "analytics", "team_content"]
    },
    "editor": {
      "allowedResources": ["dashboard", "posts", "drafts", "published_content"]
    },
    "viewer": {
      "allowedResources": ["dashboard", "reports", "published_content"]
    },
    "guest": {
      "allowedResources": ["dashboard"]
    }
  }
}
```

## 2. Declare it as an asset

`example/pubspec.yaml`:

```yaml
flutter:
  assets:
    - assets/policies/
```

## 3. Create a controller with an asset loader

```dart
_controller = PolicyEngineController.withRepository(
  repository: InMemoryPolicyRepository(),
  assetLoader: const FlutterAssetLoader(),
);
```

`PolicyEngineController.inMemory(assetLoader: const FlutterAssetLoader())` does
the same.

## 4. Load and handle the result

```dart
Future<void> _loadFromAsset() async {
  final result =
      await _controller.loadPoliciesFromAsset('assets/policies/user_roles.json');

  setState(() {
    _initialized = result.isOk;
    _lastResult = switch (result) {
      Ok() => 'Loaded from assets/policies/user_roles.json',
      Err(:final error) => error.message,
    };
  });
}
```

The demo has a **Reload from asset** button that calls `_loadFromAsset` again.
Each load replaces the current policy, and gated widgets update.

## What can go wrong

| Problem | Result |
|---|---|
| The asset path is wrong or not declared in `pubspec.yaml` | `Err(StorageFailure)` |
| The file isn't valid JSON | `Err(ParseFailure)` |
| The file has no top-level `roles` key | `Err(ParseFailure)` |
| A role uses the v1 `allowedContent` key | That role is skipped and a warning is logged. Other roles still load. |
| The controller was created without an `assetLoader` | `Err(InvalidPolicyFailure)` |
