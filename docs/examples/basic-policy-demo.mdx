# Basic Policy Demo

The first screen of the [example app](https://github.com/aspicas/flutter_policy_engine/tree/main/example).
It loads an inline policy map, lets you pick a role and a resource, and shows the
decision two ways: through `evaluateAccess` and through a `PolicyGate`.

Run it with:

```bash
cd example
flutter run
```

## The policy

`example/lib/demo_content.dart` defines five roles in the v2 schema:

```dart
const Map<String, dynamic> kDemoPolicy = <String, dynamic>{
  'roles': <String, dynamic>{
    'admin': <String, dynamic>{
      'allowedResources': <String>[
        'dashboard', 'settings', 'users', 'reports', 'analytics', 'admin_panel',
      ],
    },
    'manager': <String, dynamic>{
      'allowedResources': <String>['dashboard', 'reports', 'analytics', 'team_content'],
    },
    'editor': <String, dynamic>{
      'allowedResources': <String>['dashboard', 'posts', 'drafts', 'published_content'],
    },
    'viewer': <String, dynamic>{
      'allowedResources': <String>['dashboard', 'reports', 'published_content'],
    },
    'guest': <String, dynamic>{
      'allowedResources': <String>['dashboard'],
    },
  },
};
```

## Owning the controller

The screen creates its controller in `initState`, loads the policy, and disposes
the controller with the screen:

```dart
class _PolicyEngineDemoState extends State<PolicyEngineDemo> {
  late final PolicyEngineController _controller;
  bool _initialized = false;

  @override
  void initState() {
    super.initState();
    _controller = PolicyEngineController.inMemory();
    _load();
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  Future<void> _load() async {
    final result = await _controller.loadPolicies(kDemoPolicy);
    setState(() => _initialized = result.isOk);
  }
}
```

## Evaluating on demand

The **Evaluate** button calls the controller directly and matches on the
`Result`:

```dart
Future<void> _evaluate() async {
  final result =
      await _controller.evaluateAccess(_selectedRole, _selectedResource);
  setState(() {
    switch (result) {
      case Ok(:final value):
        _lastResult = value.isGranted ? 'GRANTED' : 'DENIED';
      case Err(:final error):
        _lastResult = 'Error: ${error.message}';
    }
  });
}
```

## Gating with `PolicyGate`

The same choice drives a `PolicyGate`. The screen is wrapped in a
`PolicyEngineScope`, so the gate finds the controller and re-evaluates every time
the dropdowns change `roleName` or `resourceId`:

```dart
PolicyEngineScope(
  controller: _controller,
  child: Scaffold(
    body: PolicyGate(
      roleName: _selectedRole,
      resourceId: _selectedResource,
      fallback: Text('Access denied to $_selectedResource'),
      child: Text('Access granted to $_selectedResource'),
    ),
  ),
)
```
