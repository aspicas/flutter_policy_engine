# Flutter Policy Engine

`flutter_policy_engine` is an authorization library for Flutter apps. You describe
which **roles** may access which **resources**. The engine answers "can this role
access this resource?" and its widgets show or hide UI based on the answer.

```dart
PolicyGate(
  roleName: currentUser.role,
  resourceId: 'settings',
  fallback: const Text('Access denied'),
  child: const SettingsScreen(),
)
```

## Features

- **RBAC with deny-by-default.** Each role lists the resource IDs it may access.
  Everything else is denied, including unknown roles.
- **Basic ABAC.** Match attributes on a `Subject` (who) against declarative rules
  and against attributes on a `Resource` (what).
- **Composable evaluators.** Combine `PolicyEvaluator`s with `denyOverrides` or
  `allowOverrides` using `CompositeEvaluator`.
- **Reactive widgets.** `PolicyEngineScope`, `PolicyGate`, and `PolicyBuilder`
  re-evaluate automatically when policies or roles change.
- **Typed errors.** Every engine operation returns a `Result` with a sealed
  `DomainFailure` instead of throwing.
- **Pluggable storage.** In-memory by default, `SharedPreferences` for
  persistence, or your own `IPolicyRepository`.
- **Injectable logging.** `NoopLogger` by default, `ConsoleLogger` for development,
  or your own `ILogger`.
- **No global state.** All runtime state lives in a `PolicyEngineController` that
  you create and own.

## How it fits together

```
 Widgets                 PolicyGate · PolicyBuilder
   │  read controller via
   ▼
 PolicyEngineScope       InheritedNotifier → rebuilds dependants on change
   │  provides
   ▼
 PolicyEngineController  ChangeNotifier — the single owner of runtime state
   │  delegates to
   ▼
 PolicyEngine            facade over the use cases (load, evaluate, role CRUD)
   │  reads / writes
   ▼
 IPolicyRepository       InMemory · SharedPreferences · your own
```

Internally the package follows Clean Architecture. The `domain` layer (entities,
evaluators, failures) is pure Dart. Flutter-specific code lives in the
`infrastructure` and `presentation` layers. Everything is exported from a single
import:

```dart
import 'package:flutter_policy_engine/flutter_policy_engine.dart';
```
